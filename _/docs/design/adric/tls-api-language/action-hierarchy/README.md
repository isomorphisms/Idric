# Filesystem action-hierarchy experiment

This directory makes two investigated client hierarchies physically
inspectable. `libtls/client` mirrors the intermediate public API;
`openssl-libssl/client` mirrors the explicit path in OpenSSL's blocking client
guide. Directory depth means only “descend into contributing mechanism” for
this experiment. It is not a proposed Adriç hierarchy, grammar, module layout,
or implementation.

Every `action.md` is a placeholder containing an action name, corresponding
real symbol or symbols, and one primary-source reference.
