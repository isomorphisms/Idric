the previous compiler. The optional equality binder is absent, erased, linear
and unrestricted, respectively. Each clause also carries a left side, a
scrutinee and a child. Reading checks all those fields independently.

The bytes were generated by WithBinding's writer with Idriç compiler
2bce7677f513d711875e978bd6f5ad28b9e54d58, TTC version 2025081600. Its
compiler sources match the default revision b2f4c2488d0aa55cd947535eb9b61ff0e6bba963
used for this change. The type workflow reads those previous bytes and
compares its writer's complete output against them. A deliberate future change
to the TTC format should account for the changed version and its readers before
updating the fixture.
